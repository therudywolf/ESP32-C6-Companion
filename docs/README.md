## Почему они здесь, а не в голове

Половина этого проекта — вещи, которых не видно из кода: что стек 802.15.4 ломает
RF-калибровку WiFi до следующей загрузки, что `esp_coex_wifi_i154_enable()`
не вызывает никто, что в шрифте нет буквы Ё. Каждая стоила часов, и каждая
вернулась бы к следующему, кто сюда придёт.

Бриф 3 — тот, который стоит прочитать первым.
